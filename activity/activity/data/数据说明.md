# 设备运动数据说明文档

## 数据集概览

本数据集包含24名受试者在不同活动类型下的设备运动传感器数据。

### 数据统计
- **受试者数量**: 24人
- **活动类型数量**: 15种
- **CSV文件总数**: 360个
- **数据文件格式**: CSV
- **采样频率**: 时间序列数据（每行一个采样点）

## 活动类型说明

| 活动代码 | 含义 | 文件夹数量 |
|---------|------|-----------|
| dws | Downstairs（下楼） | 3个 |
| jog | Jogging（慢跑） | 2个 |
| sit | Sitting（坐） | 2个 |
| std | Standing（站立） | 2个 |
| ups | Upstairs（上楼） | 3个 |
| wlk | Walking（走路） | 3个 |

**说明**: 每种活动类型后面的数字可能表示不同的实验条件、测量次数或实验版本。

## 数据文件说明

### 1. 传感器数据文件（CSV格式）

**文件命名规则**: `sub_[受试者编号].csv`

**位置**: `data/A_DeviceMotion_data/A_DeviceMotion_data/[活动类型]/sub_[编号].csv`

**示例**: `dws_1/sub_1.csv` 表示受试者1进行下楼活动（类型1）的数据

**数据结构**:

每个CSV文件包含以下列：

| 列名 | 说明 | 数据类型 |
|-----|------|---------|
| Unnamed: 0 | 时间索引（采样点序号） | 整数 |
| attitude.roll | 姿态-滚转角（弧度） | 浮点数 |
| attitude.pitch | 姿态-俯仰角（弧度） | 浮点数 |
| attitude.yaw | 姿态-偏航角（弧度） | 浮点数 |
| gravity.x | 重力加速度-x方向（g） | 浮点数 |
| gravity.y | 重力加速度-y方向（g） | 浮点数 |
| gravity.z | 重力加速度-z方向（g） | 浮点数 |
| rotationRate.x | 旋转速率-x轴（rad/s） | 浮点数 |
| rotationRate.y | 旋转速率-y轴（rad/s） | 浮点数 |
| rotationRate.z | 旋转速率-z轴（rad/s） | 浮点数 |
| userAcceleration.x | 用户加速度-x方向（m/s²） | 浮点数 |
| userAcceleration.y | 用户加速度-y方向（m/s²） | 浮点数 |
| userAcceleration.z | 用户加速度-z方向（m/s²） | 浮点数 |

**数据特点**:
- 每个文件约1500-1700行数据
- 数据按时间顺序排列
- 所有传感器数据为时间序列格式

### 2. 受试者信息文件

**文件路径**: `data/data_subjects_info.csv`

**数据结构**:

| 列名 | 说明 | 数据类型 |
|-----|------|---------|
| code | 受试者编号（1-24） | 整数 |
| weight | 体重（单位：kg） | 浮点数 |
| height | 身高（单位：cm） | 整数 |
| age | 年龄（岁） | 整数 |
| gender | 性别（0=女性，1=男性） | 整数 |

**受试者统计**:
- 年龄范围: 18-46岁
- 体重范围: 48-102 kg
- 身高范围: 161-190 cm
- 性别分布: 包含男性和女性

## 注意事项

1. **数据完整性**: 每个活动类型文件夹下都应包含24个受试者的数据文件（sub_1.csv 到 sub_24.csv）
2. **时间单位**: 数据为离散采样点，未明确标注采样频率，需要根据实际应用场景判断
3. **坐标系**: 传感器数据采用设备坐标系，方向定义需参考设备文档
4. **数据单位**: 
   - 角度使用弧度制
   - 重力加速度单位为g（9.8 m/s²）
   - 旋转速率单位为弧度/秒
   - 用户加速度单位为m/s²
